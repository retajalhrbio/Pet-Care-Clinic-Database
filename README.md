\# 🐾 Pet Care Clinic Database Management System



\## 📌 Project Overview



The Pet Care Clinic Database Management System is a university team project designed to organize and manage information related to pet owners, pets, appointments, and vaccinations.



The database was designed and implemented using \*\*MySQL\*\*, with a focus on relational database design, data organization, and SQL queries.



\## 🛠️ Technologies \& Concepts



\- MySQL

\- SQL

\- Database Design

\- Entity-Relationship Diagrams (ERD)

\- Relational Schema

\- Primary and Foreign Keys

\- Database Constraints

\- SQL Queries and Views



\## 📂 Database Structure



The database consists of four main tables:



\- \*\*Owners:\*\* Stores pet owners' information.

\- \*\*Pets:\*\* Stores pet details and links each pet to its owner.

\- \*\*Appointments:\*\* Manages appointment records for pets.

\- \*\*Vaccinations:\*\* Tracks vaccination records and upcoming due dates.



\### Relationships



\- Owners → Pets: One-to-Many (1:M)

\- Pets → Appointments: One-to-Many (1:M)

\- Pets → Vaccinations: One-to-Many (1:M)



\## ✨ Project Features



\- Relational database design using an ER diagram.

\- Database implementation using MySQL.

\- Table creation with primary and foreign keys.

\- Data validation using database constraints.

\- Sample data insertion.

\- Data retrieval using SELECT queries.

\- Aggregate functions, JOIN queries, and subqueries.

\- SQL views for generating reports.
